# 如何使用 Map 实现 LRU 缓存？

## 问题

请使用 JavaScript 和 `Map` 实现一个简化版 LRU 缓存，提供 `get` 和 `set`。读取或覆盖已有数据时要把它更新为最近使用；超过容量时淘汰最久未使用的数据。

## 30 秒口述答案

LRU 的核心是维护“最久未使用到最近使用”的顺序。JavaScript 的 `Map` 按插入顺序迭代，所以访问一个键时先删除再重新插入，就能把它移动到末尾。新增后如果超过容量，删除 `map.keys().next().value`，也就是当前最旧的键。

## 详细原理

### 顺序约定

`Map` 的开头保存最久未使用项，末尾保存最近使用项。`get` 命中和 `set` 覆盖都算一次使用，因此都要刷新顺序。

### 为什么先 delete 再 set

直接覆盖已有键只会修改值，不能明确改变原插入位置。删除后重新插入，键会移动到 `Map` 末尾。

### 面试版边界

本题只实现容量淘汰，不包含 TTL、持久化、并发安全和权重计算。若值本身允许是 `undefined`，应再提供 `has` 来区分未命中。

## JavaScript 示例

运行环境：现代浏览器或 Node.js 23.11.1。

```javascript
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.cache = new Map();
  }

  get(key) {
    if (!this.cache.has(key)) return -1;

    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value);
    return value;
  }

  set(key, value) {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    }

    this.cache.set(key, value);
    if (this.cache.size > this.capacity) {
      const oldestKey = this.cache.keys().next().value;
      this.cache.delete(oldestKey);
    }
  }
}

const cache = new LRUCache(2);
cache.set("a", 1);
cache.set("b", 2);
cache.get("a");
cache.set("c", 3); // 淘汰 b
console.log(cache.get("b")); // -1
```

常见 JavaScript 引擎中，`get` 和 `set` 可视为平均 `O(1)`；空间复杂度为 `O(capacity)`。

## 常见追问

1. **为什么 `get` 也要刷新顺序？** LRU 的“使用”包含读取，否则实现更接近按写入时间淘汰。
2. **如果需要缓存 `undefined` 怎么办？** 不要只依赖 `get` 的返回值，应额外提供 `has` 或使用明确的哨兵值。
3. **不用 Map 怎么实现？** 使用哈希表定位节点，再用双向链表维护新旧顺序。

## 易错点

- `get` 命中后没有刷新顺序。
- 覆盖已有键时没有先删除，导致顺序没有更新。
- 容量超限时删除末尾，反而淘汰最近使用项。
- 把 LRU 和按时间过期的 TTL 缓存混为一谈。
