要彻底搞懂 Fiber，我们要跳出 React 的代码，站在**浏览器的宏观视角**来看待页面的渲染机制。

浏览器的渲染有一个铁律：**“JS 执行”和“页面绘制”是互斥的，它们共用同一个主线程。**

主流显示器的刷新率是 60Hz，这意味着浏览器必须在 16.6 毫秒（1000ms / 60）内完成一帧的全部工作（JS 执行 + 布局 + 绘制）。如果 JS 霸占主线程超过 16.6 毫秒，浏览器就无法按时绘制屏幕，用户看到的直接后果就是——**卡顿、掉帧（Jank）**。

React 16 引入的 Fiber 架构，正是为了解决这个致命的“主线程霸权”问题。

### 🚨 痛点时刻：React 15 的“一波流”危机 (Stack Reconciler)

在 React 15 时代，底层的对比算法被称为 **Stack Reconciler（栈协调器）**。

它的工作方式是**同步递归**。当组件状态更新时，React 会从树的根节点开始，一层一层往下递归对比（Diff）。

**致命缺陷在于它的底层依赖了 JavaScript 的原生“函数调用栈”。**

只要递归一开始，这棵虚拟 DOM 树不遍历完，这个庞大的调用栈就**绝对无法被打断**。

假设你的页面非常复杂，这次 Diff 需要耗时 100 毫秒。在这 100 毫秒内，主线程被 React 死死锁住。即使用户在这期间疯狂点击按钮，或者页面上有丝滑的 CSS 动画，浏览器也只能“装死”，因为主线程在忙着执行 JS，没空去处理点击事件和重新绘制页面。

### 🛠️ Fiber 的破局之道：将大象切片 (Time Slicing)

React 团队意识到，不能再依赖原生的 JS 调用栈了，他们必须自己实现一套**可以随时暂停、恢复、甚至放弃**的调度机制。这就是 Fiber 诞生的核心驱动力。

Fiber 架构主要在底层做了两件惊天动地的大事：

#### 1. 颠覆数据结构：从“树”变成“链表”

为了能够随时暂停和恢复，React 把原本深不见底的“树型递归”，拍平成了基于指针的“单向链表”。

每一个虚拟 DOM 节点，现在变成了一个个独立的 **Fiber 节点（工作单元）**。每个 Fiber 节点身上都有三个极其关键的指针：

- `child`：指向第一个子节点
- `sibling`：指向右边的亲兄弟
- `return`：指向父节点

**这有什么用？**

这相当于给遍历过程加入了“存档点”。React 现在不是一次性扎进深渊，而是一个个节点往下走。走到任何一个节点，哪怕突然暂停了，只要看着这三个指针，下次回来时依然能精准找到“我刚执行到哪了，下一步该去哪”。

#### 2. 时间分片 (Time Slicing) 与协作式调度

有了链表的存档能力，React 开始和浏览器玩起了“默契配合”。

React 会把 100 毫秒的巨大 Diff 任务，切碎成几十个几毫秒的小任务。

每次处理完一个 Fiber 节点（耗时不到 1 毫秒），React 引擎都会抬头看一眼浏览器的钟：“主线程，你现在有紧急任务要处理吗？（比如用户输入、动画）”

- 如果浏览器说：“有！我要画动画！” ➡️ React 立刻暂停手头的 Diff，让出主线程。浏览器画完动画后，React 再读档恢复，继续处理下一个 Fiber。
- 如果浏览器说：“我很闲。” ➡️ React 就继续往下处理。

这种机制在底层借鉴了浏览器的 `requestIdleCallback` API 思想，彻底消灭了长任务阻塞。

### 👑 满分面试话术总结

面对这道架构题，直接用这段话完成绝杀：

“React 16 引入 Fiber 架构，根本上是为了解决 React 15 **同步递归（Stack Reconciler）导致长任务阻塞浏览器主线程**的痛点。

在 React 15 中，虚拟 DOM 的比对过程依赖于原生的 JS 调用栈。一旦开始渲染庞大的组件树，它就无法被中断。如果耗时超过浏览器的 16.6ms 帧限制，就会阻塞浏览器的渲染和事件响应，导致动画掉帧和交互卡顿。

Fiber 架构重写了底层的协调机制。首先，在数据结构上，它将树形的递归遍历改造成了基于 `child`、`sibling`、`return` 指针的**链表遍历**，让每一次节点处理变成了一个可随时中断和恢复的最小工作单元（Fiber 节点）。

其次，在执行模型上，它实现了**时间分片（Time Slicing）**。React 会在浏览器每一帧的空闲时间内执行这些小任务。一旦发现浏览器有更高优先级的任务（如用户交互、渲染绘制），Fiber 能够立刻让出主线程控制权，等主线程空闲后再读档恢复。这使得 React 从‘同步阻塞渲染’跨越到了‘异步可中断渲染’，为后续的并发特性打下了底层地基。”
