# 如何遍历、查找和扁平化递归树？

## 问题

给定由 `{ id, children }` 组成的树，请使用 JavaScript 实现深度优先遍历、广度优先遍历和按 ID 查找。深度优先遍历收集到的节点数组同时作为树的扁平化结果。

## 30 秒口述答案

DFS 先访问当前节点，再递归子节点，代码短，适合查找和扁平化嵌套结构。BFS 使用队列逐层访问，适合寻找距离根更近的节点。遍历所有节点时二者都是 `O(n)`；递归 DFS 的额外空间与树高有关，极深树可能栈溢出，BFS 的队列空间与树的最大宽度有关。

## 详细原理

### DFS 与扁平化

前序 DFS 的顺序是“当前节点 -> 从左到右访问子树”。把每次访问的节点推入结果数组，就得到前序扁平化结果。

### BFS

BFS 把根节点放入队列，取出一个节点后再把其 children 放到队尾。代码使用 `index` 读取数组，而不是反复 `shift()`，避免每次移动剩余元素。

### 输入边界

本题默认输入是真正的树，不存在循环引用或共享子节点。如果数据可能成环，就要增加 `visited` 集合，否则会无限遍历。

## JavaScript 示例

运行环境：现代浏览器或 Node.js 23.11.1。

```javascript
function dfs(tree) {
  const result = [];

  function walk(nodes) {
    for (const node of nodes) {
      result.push(node);
      walk(node.children || []);
    }
  }

  walk(tree);
  return result;
}

function bfs(tree) {
  const result = [];
  const queue = [...tree];

  for (let index = 0; index < queue.length; index += 1) {
    const node = queue[index];
    result.push(node);
    queue.push(...(node.children || []));
  }

  return result;
}

function findById(tree, id) {
  for (const node of tree) {
    if (node.id === id) return node;

    const found = findById(node.children || [], id);
    if (found) return found;
  }
  return null;
}

const tree = [
  { id: "a", children: [{ id: "a-1", children: [] }] },
  { id: "b", children: [] },
];

console.log(dfs(tree).map((node) => node.id)); // a, a-1, b
console.log(bfs(tree).map((node) => node.id)); // a, b, a-1
```

完整遍历和最坏情况查找的时间复杂度是 `O(n)`。递归 DFS 的额外空间为 `O(h)`，BFS 为 `O(w)`，其中 `h` 是树高，`w` 是队列峰值。

## 常见追问

1. **怎样避免极深树导致递归栈溢出？** 使用显式栈改写为迭代 DFS。
2. **DFS 和 BFS 查找有什么区别？** DFS 优先深入子树，BFS 优先找到层级更浅的匹配项。
3. **怎样处理 branch 和 loop 有不同子数组字段的业务树？** 先写一个统一的 `getChildren(node)`，遍历算法只依赖它。

## 易错点

- 递归时漏掉返回值，导致深层查找结果无法向上返回。
- BFS 反复使用 `shift()`，产生不必要的数组移动。
- 扁平化过程中修改原 children，破坏源树。
- 数据可能成环时没有使用 `visited`。
