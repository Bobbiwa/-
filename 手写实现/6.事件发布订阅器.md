# 如何实现事件发布订阅器？

## 问题

请使用 JavaScript 实现一个事件发布订阅器，提供 `on`、`off`、`once` 和 `emit`。同一事件可以有多个监听器；同一个函数重复订阅时自动去重；`once` 监听器只能执行一次，即使它在回调中再次触发同一事件。

## 30 秒口述答案

我用 `Map` 保存事件名到监听器集合的映射，用 `Set` 自动去重。`on` 添加监听器，`off` 删除监听器，`emit` 遍历当前监听器的快照并同步执行。`once` 会包装原回调，并且一定要在调用原回调之前先取消订阅，否则回调中嵌套触发同一事件时会再次执行。

## 详细原理

### 数据结构

`Map` 负责按事件名找到监听器集合，`Set` 保证同一个函数不会重复注册，并保持插入顺序。

### 为什么 emit 遍历快照

使用 `[...listeners]` 创建当前轮快照。这样监听器在派发过程中增加或删除订阅时，不会干扰本轮遍历；新监听器从下一次 `emit` 开始执行。

### once 的重入问题

包装函数必须先 `off`，再调用用户回调。若顺序相反，用户回调中再次 `emit` 时，包装器尚未删除，会执行第二次。

## JavaScript 示例

运行环境：现代浏览器或 Node.js 23.11.1。

```javascript
class EventEmitter {
  constructor() {
    this.events = new Map();
  }

  on(event, listener) {
    if (!this.events.has(event)) {
      this.events.set(event, new Set());
    }
    this.events.get(event).add(listener);
    return () => this.off(event, listener);
  }

  off(event, listener) {
    const listeners = this.events.get(event);
    if (!listeners) return;

    listeners.delete(listener);
    if (listeners.size === 0) this.events.delete(event);
  }

  once(event, listener) {
    const wrapper = (...args) => {
      this.off(event, wrapper);
      listener(...args);
    };
    return this.on(event, wrapper);
  }

  emit(event, ...args) {
    const listeners = this.events.get(event);
    if (!listeners) return;

    [...listeners].forEach((listener) => listener(...args));
  }
}

const emitter = new EventEmitter();
emitter.once("done", (id) => console.log("完成", id));
emitter.emit("done", "flow-1");
emitter.emit("done", "flow-2"); // 不再执行
```

`on`、`off` 平均为 `O(1)`，`emit` 为 `O(m)`，其中 `m` 是该事件的监听器数量。

## 常见追问

1. **发布订阅和观察者模式完全相同吗？** 不宜绝对等同。发布订阅通常通过事件通道解耦双方，观察者常由被观察对象直接维护观察者。
2. **如果要允许同一个函数重复订阅怎么办？** 把 `Set` 改为数组，并明确 `off` 是移除一次还是全部。
3. **异步监听器怎么处理？** 当前 `emit` 是同步且不等待返回值；可另写 `emitAsync`，再决定串行、并行和失败策略。

## 易错点

- `once` 在用户回调执行后才取消，嵌套 `emit` 时会重复触发。
- 直接遍历正在被修改的集合，导致本轮新增或删除行为不清晰。
- 删除最后一个监听器后仍保留空集合。
- 捕获监听器异常后静默吞掉，使调用方无法发现失败。
