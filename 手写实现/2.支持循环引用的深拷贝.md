# 如何实现支持循环引用的深拷贝？

## 问题

请使用 JavaScript 实现一个面试版深拷贝，支持普通对象、数组、`Date`、`RegExp`、`Map`、`Set` 和循环引用，并保证同一个源对象被多处引用时，克隆结果仍指向同一个克隆对象。

## 30 秒口述答案

深拷贝复制的是对象图。递归前先查看 `WeakMap`，第一次遇到对象时先创建克隆容器并记录映射，再递归子属性。这样再次遇到同一个对象时可以直接返回已有克隆，既能处理循环引用，也能保留共享引用。`Date`、`RegExp`、`Map` 和 `Set` 需要按类型单独创建，不能只当普通对象复制。

## 详细原理

### 为什么需要 WeakMap

若 `source.self === source`，递归处理 `self` 时会再次遇到源对象。只有提前保存“源对象 -> 克隆对象”的映射，才能终止递归。同一机制也会保留 `source.a === source.b` 的共享关系。

### 为什么要分类处理

数组需要数组容器；`Date` 和 `RegExp` 的值不在普通可枚举属性中；`Map` 和 `Set` 还要递归复制其中的键和值。

### 面试版边界

本实现使用 `Object.keys`，只处理可枚举字符串属性，不复制 Symbol、不可枚举属性、属性描述符和自定义原型。函数和原始值保持原值。它是用于说明核心思路的面试子集，不等价于原生 `structuredClone`。

## JavaScript 示例

运行环境：现代浏览器或 Node.js 23.11.1。

```javascript
function deepClone(value, cache = new WeakMap()) {
  if (typeof value !== "object" || value === null) return value;
  if (cache.has(value)) return cache.get(value);

  if (value instanceof Date) {
    const result = new Date(value.getTime());
    cache.set(value, result);
    return result;
  }

  if (value instanceof RegExp) {
    const result = new RegExp(value.source, value.flags);
    cache.set(value, result);
    return result;
  }

  if (value instanceof Map) {
    const result = new Map();
    cache.set(value, result);
    value.forEach((item, key) => {
      result.set(deepClone(key, cache), deepClone(item, cache));
    });
    return result;
  }

  if (value instanceof Set) {
    const result = new Set();
    cache.set(value, result);
    value.forEach((item) => result.add(deepClone(item, cache)));
    return result;
  }

  const result = Array.isArray(value) ? [] : {};
  cache.set(value, result);

  Object.keys(value).forEach((key) => {
    result[key] = deepClone(value[key], cache);
  });
  return result;
}

const source = { name: "flow" };
source.self = source;
const cloned = deepClone(source);
console.log(cloned !== source, cloned.self === cloned); // true true
```

若对象图共有 `n` 个属性和集合元素，时间和空间复杂度通常都是 `O(n)`；递归深度过大仍可能导致调用栈溢出。

## 常见追问

1. **为什么 JSON 序列化不是通用深拷贝？** 它不能处理循环引用，会丢失或改变 `undefined`、函数、`Date`、`Map`、`Set` 等值。
2. **为什么使用 WeakMap？** 它按对象身份保存已克隆结果，既能防止循环，也能保留重复引用关系。
3. **生产代码怎样选择？** 先判断数据类型和语义；适用时优先使用 `structuredClone`，否则使用成熟库或业务专用转换。

## 易错点

- 递归完子属性后才写入缓存，循环引用仍会无限递归。
- 只处理数组和对象，导致 `Date`、`Map` 等类型丢失。
- 每次遇到相同对象都重新创建，破坏共享引用关系。
- 宣称面试版实现完整等价于 `structuredClone`。
