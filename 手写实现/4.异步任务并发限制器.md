# 如何实现异步任务并发限制器？

## 问题

请使用 JavaScript 实现 `mapLimit(list, limit, handler)`。同时执行的任务数量不能超过 `limit`，最终结果要保持输入顺序；任一任务失败时返回的 Promise reject，并停止领取尚未开始的新任务。

## 30 秒口述答案

我会启动不超过 `limit` 个 worker，并用一个共享索引分配任务。每个 worker 循环领取下一个索引，等待任务完成后再继续，所以同时运行数量不会超过 worker 数。结果写回原索引，因此返回顺序不受完成顺序影响。任一 worker 抛错后，`Promise.all` 会 reject；其他已开始的任务不能被强制停止，但通过失败标记可以阻止它们继续领取新任务。

## 详细原理

### 为什么能限制并发

worker 数量最多为 `limit`，每个 worker 同一时间只等待一个 `handler`，因此正在运行的任务数不会超过 worker 数。

### 为什么共享索引不会重复领取

JavaScript 在一次同步执行中完成读取和递增 `index`，之后才会遇到 `await` 让出执行权，所以每次领取的索引不同。

### 失败边界

第一个任务失败后设置 `failed`，阻止其他 worker 完成当前任务后继续领取。已经运行的异步操作仍会继续，若要真正取消，需要让 `handler` 接收并响应 `AbortSignal`。

## JavaScript 示例

运行环境：现代浏览器或 Node.js 23.11.1。

```javascript
async function mapLimit(list, limit, handler) {
  if (limit <= 0) throw new RangeError("limit 必须大于 0");

  const result = new Array(list.length);
  let index = 0;
  let failed = false;

  async function worker() {
    while (!failed) {
      const current = index;
      index += 1;

      if (current >= list.length) return;

      try {
        result[current] = await handler(list[current], current);
      } catch (error) {
        failed = true;
        throw error;
      }
    }
  }

  const workers = Array.from(
    { length: Math.min(limit, list.length) },
    () => worker(),
  );

  await Promise.all(workers);
  return result;
}

mapLimit([3, 1, 2], 2, (seconds) =>
  new Promise((resolve) => setTimeout(() => resolve(seconds), seconds * 100)),
).then(console.log); // [3, 1, 2]
```

时间复杂度为 `O(n)`；结果数组空间为 `O(n)`，worker 状态为 `O(limit)`。

## 常见追问

1. **为什么不能写 `Promise.all(list.map(handler))`？** 因为 `map` 会立即调用全部 handler，所有任务已经启动。
2. **失败后正在运行的任务会停止吗？** 不会，只能停止领取新任务；真正取消要由任务配合 `AbortSignal`。
3. **怎样改成收集全部成功和失败结果？** worker 内捕获错误并把 `{ status, value/reason }` 写回结果，而不是继续抛出。

## 易错点

- 先创建所有 Promise，再尝试限制等待数量，实际没有限制任务启动。
- 完成后使用 `push`，导致结果按完成顺序排列。
- `limit` 大于任务数时仍创建很多空 worker。
- 任务失败后其他 worker 仍继续领取新任务。
